# DECISIONS

Lightweight ADRs. Format: **ID — decision** · why · alternatives rejected · revisit when. Decisions are made unless the brief already fixed them; those that change the brief's stack are marked ⚠.

| ID | Decision | Why | Alternatives / revisit |
|---|---|---|---|
| D-01 | **pnpm workspaces + Turborepo** monorepo (`apps/*`, `packages/*`) | Shared authz/domain/schemas between web, realtime and worker without publishing | Nx (heavier); polyrepo (drift). |
| D-02 | **Pin Node LTS (22 or 24) via `.nvmrc`/`engines`**; install pnpm with `npm i -g pnpm` | Local machine runs Node 25.6 (odd, non-LTS) and has no pnpm; Node 25 also no longer ships Corepack | Use whatever is installed (rejected: CI/prod drift). |
| D-03 | **Drizzle ORM** + SQL migrations | SQL-first, first-class RLS/`tstzrange`/tsvector via raw SQL, light runtime | Prisma (weaker Postgres-specific features, heavier engine). |
| D-04 | **Postgres RLS + app-level `can()`** (two layers) | A bug in either layer must not leak tenant data | App-only checks (rejected). |
| D-05 | **`defineRoute` wrapper is mandatory** for every handler; enforced by lint rule + test | Makes server-side authz/validation/audit structural | Convention only (rejected). |
| D-06 | **Separate `apps/realtime` (Fastify + Socket.IO + Yjs)** and **`apps/worker` (BullMQ)**, both consuming `packages/domain` | Next route handlers are not a good WebSocket host; workers scale separately | Everything in Next (rejected); NestJS (more ceremony than needed). |
| D-07 | **Socket.IO** (Redis adapter) for chat/presence; **Yjs** for boards/notes/scouting text; **row-version optimistic concurrency** for structured objects | Rooms/acks/reconnect built in; CRDT for concurrent text/canvas; simple field-level merge for schedules/tasks | `ws` raw (rebuild rooms/ack); OT (complex). |
| D-08 | **Auth.js behind `packages/authn`** (default; pending Q1). DB sessions; realtime service gets a short-lived signed WS ticket from web | Keeps identity in our DB (DPDP posture), shared verification path | Clerk (faster, US vendor, per-MAU). Verify Auth.js maintenance status at M0 scaffold. |
| D-09 | **Contracts: default-deny to everyone except Owner/Manager;** the subject player can be granted a specific document explicitly (audited, revocable), off by default | Satisfies "Player cannot read contracts" while allowing transparency when the org chooses | Player read-own by default (contradicts brief). |
| D-10 | **Wellness is default-deny even for Owner;** player-issued expiring grants; RLS-enforced; reads audited | Brief: "visible only to the player and explicitly permitted staff" | Role-based access (rejected: too broad). |
| D-11 | **Envelope encryption (AES-256-GCM) for contracts and provider tokens**, master key from env/KMS, key id on the row; signed URLs only | Encryption at rest independent of storage vendor; enables key rotation | Storage-level SSE only (kept in addition). |
| D-12 | **In-app e-sign flow behind a `SignatureProvider` interface**; captures email OTP, intent, timestamp, IP/UA, SHA-256 of document | Ships without vendor lock-in; swap to a recognised provider (e.g. Aadhaar eSign) where required | Integrate a vendor first (cost, lock-in). Legal caveats surfaced in product. |
| D-13 | **Money as `bigint` minor units + ISO 4217**; no floats; FX display-only with stored rate | Correctness of payroll/prize splits | `numeric` (fine but easy to misuse in JS). |
| D-14 | **WebGL only on non-data-dense surfaces** (auth, onboarding, game switcher, Match Day countdown, header ambience), lazy + guarded with fallbacks | Reconciles "alive UI" with Lighthouse ≥ 90 and 60 fps | WebGL everywhere (rejected). |
| D-15 | **Glass = CSS `backdrop-filter` by default;** `liquid-glass-js` evaluated in an M0 spike, adopted only for a few static surfaces if it holds 60 fps | Depends on html2canvas (README warns about perf); poor fit for live-updating content | Adopt globally (rejected). **Revisit after M0 spike.** |
| D-16 | **`liquid-logo` used as a design tool, not a dependency** (it is a standalone app); port the shader idea to R3F only for the brand mark | It is not an npm package | Vendor its source (unneeded weight). |
| D-17 | **`ruflo` not installed by default** (pending Q5); `superpowers` and `ui-aesthetics-skill` welcome | ruflo is a large multi-agent harness with its own MCP server; overlaps built-in subagents and widens the execution surface of a repo holding sensitive-data code | Install (your call). |
| D-18 | **Konva (`react-konva`) for tactical boards;** React Flow considered for brackets (spike in M7) | Boards need freeform drawing, tokens, layers; React Flow is a node-graph tool | React Flow for boards (poor fit); Excalidraw embed (hard to theme/version). |
| D-19 | **Charts: Recharts (themed) + `dataviz` skill rules**; custom SVG where needed for form curves and heatmaps | Fast to build, animatable; palette and encodings governed by `dataviz` for colour-blind safety | visx (more control, more code); D3 raw. |
| D-20 | **Game Module registration via codegen glob** of `packages/games/*/module.ts`; game ids are strings, not DB enums | "Add a 7th game without touching core" is testable in CI | Central registry file (touches core). |
| D-21 | **Stats stored as JSONB validated by the module's zod schema, with `schema_version`;** dashboards render from declarative `MetricDef[]` | Six different stat shapes without six sets of tables | Per-game tables (violates module goal). |
| D-22 | **Every match/stat row carries `source` + provenance; adapters store raw payloads in object storage;** demo rows have `is_demo` and a persistent UI badge | Honest data; reprocessing without refetch; "never fake data silently" | — |
| D-23 | **Riot: adapter built behind interface with mock + CSV as default;** production key application submitted at end of M2; **Live Guidance for Riot games is human-authored only** | Personal keys are refused for VALORANT; RSO opt-in mandatory; unfair-advantage policy | Wait for key before building (blocks M3). |
| D-24 | **Arena Bridge companion** (Node CLI first) for GSI: localhost → authenticated ingest endpoint | Sanctioned by Valve config-file model; no inbound connections to user PCs | Browser-only (impossible: GSI posts to localhost). |

| D-30 | **AI assistant (M8) uses Claude API, retrieval-only over org data, must cite source rows, and may not output a stat that is not in the retrieved data** | Brief: "never invent statistics" | Free-form generation (rejected). |
